The agent chat can sit beside the page as well as below it, and the file tree
now pushes it rather than being spanned by it. Settings → Agents picks the
place and the size that goes with it; the palette moves it without going there.

Its edge drags — the top when it sits below, the left when it sits beside.
The "Flesh out" button is gone from the page header; the palette command
that did the same thing stays.

Beside the page, the chat and the git panel take turns: they want the same
column, so opening one closes the other.

Settings gains a real Agents section: which agent answered, the binary, the
instruction "Flesh out" sends (editable, with a reset), the copyable command,
and where the chat sits. The panel buttons now leave Settings instead of
toggling something you cannot see.

The git panel gets the same header bar as the chat and the tabs, with pull
and push in it as “Pull ↓” and “Push ↑”, carrying their counts. The branch picker moved to
the rail beside the repository, the commit box moved to the top of the panel,
and the repository's name is no longer repeated inside it.
