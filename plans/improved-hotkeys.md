# improved-hotkeys

<br />

I think we should support keybindings for common tasks

- Like in VS Code, I like to Cmd + K, Cmd + W to close all open windows
- Or Neovim keybindings 
- Or other common editing keybindings

But the counter point is that editing is actual minimal these days, agents are the ones doing most of the writing and we should focus on editing. So having build in minimal keybindings might be enough.

We maybe should also have a way to see all shortcuts. Cmd + ?

And then we allow them to be customised, might be a better alternative to built-in keybindings which we can easily bring in as packs after the fact.
