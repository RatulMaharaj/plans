# Add-review-skill

Reviewing Pull Requests is THE hero use case of this app for me.

We should add a skill on how to use plans to create PR review materials. This skill needs to ship with the app and should include:

- Things like mermaid for visuals <https://mermaid.ai/open-source/syntax/requirementDiagram.html>
- Mermaid supports a lot of types of visuals such as swimlanes, Gantt, Pies, Quadrants and more. We should document this
- Code blocks for snippets explaining key code changes that need to be understood etc
- We should document how review docs should be split up and ordered to make it easy for the user to digest now just one massive document.

Should we have a way to see open PRs in the command palette or git panel to make it easy to get to?

I want an easy way to manage my installed skills - maybe Command Palette and it opens in an editor from the installed location?
