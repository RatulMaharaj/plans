Looped Plans

A small desktop app for reading and editing the markdown in your local git repositories — without opening the whole repo in an editor.

Download

Free and open source · GitHub

Every repo at once

Add any local git repository. All their markdown shows up in one tree, remembered between launches.

Nothing is lost

The file on disk is the only buffer, and every save is checked against the version you read — so an edit from elsewhere is caught, not clobbered.

Page, source, diff

Three ways to look at the same file, all editable, all the same buffer.

Git, built in

Branches, pull and push, staging, undo and commit — shelling out to your own git, with your own keys and hooks.

Built with Tauri and Milkdown. Type is Vollkorn, Work Sans, and Space Mono, from Open Foundry.
This site and the app count anonymous usage. Nobody is identified, and no file name, path, or word of your writing ever leaves your machine — the app's Settings → Privacy turns it off.
