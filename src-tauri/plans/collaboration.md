# collaboration.md

I have some collaboration ideas.

We don’t need user accounts. The repo + access to it has everything we need. 

Comments are already a markdown native thing - we should support right click new comment + a shortcut for it. If we could support comment threads somehow inside a markdown comment that would be cool too.

I also like the idea of having some plans ui generated from the frontmatter in a md file like status of a plan as an example. Maybe there are other things too?
