# Getting started

This folder is what the **Plans** app loads. Anything ending in `.md` here shows
up in the sidebar, and edits are written straight back to disk.

## How it fits together

- Write plans here with Claude Code, or create them with the **New** button.
- Edit them in the WYSIWYG pane — the file on disk stays plain markdown.
- Stage, commit, and push from the git panel on the right.
